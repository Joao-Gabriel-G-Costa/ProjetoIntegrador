Projeto desenvolvido como Projeto Integrador – 2025/2 do curso de Engenharia de Software da Faculdade SENAI FATESG.

## 🎯 Objetivos

- Registrar veículos da frota com informações detalhadas

- Categorizar despesas por tipo

- Registrar movimentações financeiras associadas a cada veículo

- Gerar relatórios gerenciais para apoio à tomada de decisão
